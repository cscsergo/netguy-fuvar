# NetguY Fuvar

Útiköltség- és fuvardíj-kalkulátor webalkalmazás (PWA), közúti távolsággal.

- Településkeresés magyar és román névvel (megye + ország megjelenítéssel)
- Közúti km és menetidő két független útvonaltervezővel (OSRM, Valhalla), eltérés esetén figyelmeztetés
- Csak oda / oda-vissza, fogyasztás-összehasonlítás (5,5 / 6 / 7 l)
- Opcionális fuvarár: a kliens csak az odautat fizeti
- Google Maps ellenőrző link, korábbi útvonalak, beállítások mentése az eszközön

## Telepítés

Statikus oldal, build nélkül: Netlify-on a publish könyvtár a repó gyökere (`netlify.toml`).
iPhone-on Safari → Megosztás → „Főképernyőhöz adás”.
